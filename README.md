# Modelo de site — Clínica Odontológica

Projeto demonstrativo criado pela Multiplik Digital para apresentação comercial a clínicas odontológicas.

## Objetivo

Mostrar uma referência premium de site/landing page com foco em:

- posicionamento;
- experiência mobile;
- conversão;
- estrutura para Google Ads;
- SEO local;
- WhatsApp e mensuração.

## Publicação no GitHub Pages

O site principal está no arquivo `index.html` da branch `main`.

Para publicar: **Settings > Pages > Deploy from a branch > main > / (root)**.

Endereço esperado: https://multiplikdigital.github.io/modelo-clinica-odontologica/

## Observação

A clínica exibida é fictícia e todo o conteúdo é demonstrativo. As imagens externas usadas no layout são de referência e devem ser substituídas por fotos reais do cliente em projetos finais.
